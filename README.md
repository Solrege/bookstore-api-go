# Bookstore API
Este proyecto es una API REST desarrollada en Golang que gestiona una tienda de libros. Proporciona funcionalidades como la creación, actualización, eliminación y consulta de libros y usuarios.

## Tecnologías Utilizadas
Lenguaje: Go (Golang)
Framework: Echo para manejar las rutas HTTP
Base de Datos: MySQL (mediante el paquete gorm)
Autenticación: JWT (JSON Web Tokens) para la autenticación de usuarios
Pagos: Integración con la API de Mercado Pago

## Funcionalidades Principales
Gestión de libros: CRUD (Crear, Leer, Actualizar, Eliminar)
Gestión de usuarios: Registro y autenticación con JWT
Manejo de errores: Implementación de middleware para la validación y manejo de errores
Gestión de pagos: Integración con Mercado Pago para procesar transacciones
